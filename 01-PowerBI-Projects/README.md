
# Olist E-commerce Power BI Dashboard

## Objective
Analyze customer behavior, sales performance, payment trends, and repeat customer patterns using the Olist Brazilian E-commerce dataset.

## Dashboard Features

### Executive Overview
- Total Revenue
- Total Orders
- Average Order Value
- Customer Satisfaction Score

### Sales Analysis
- Revenue trend over time
- Top product categories
- Payment method analysis

### Customer Analysis
- Repeat customers
- Customer purchase behavior
- Geographic distribution

## Tools Used
- Power BI
- SQL
- Excel
- DAX

## Key Insights
- Identified top revenue-generating categories
- Analyzed customer retention patterns
- Evaluated payment method preferences
