
Olist Customer Retention Analysis
Project Overview

This project analyzes customer retention behavior using the Olist Brazilian E-Commerce dataset. The goal is to understand customer purchasing patterns, identify repeat customers, measure retention rate, evaluate customer satisfaction impact, and calculate customer lifetime value.

The analysis was performed using SQL by combining customer, order, payment, and review datasets to generate business insights related to customer loyalty and long-term value.

Objectives
Understand the total customer base of Olist.
Analyze customer purchase frequency.
Identify repeat customers.
Calculate customer retention rate.
Compare one-time and returning customer behavior.
Analyze whether customer satisfaction influences repeat purchases.
Identify high-value customers based on lifetime spending.
Dataset Used

The analysis uses the following Olist datasets:

olist_customers_dataset
olist_orders_dataset
olist_order_payments_dataset
olist_order_reviews_dataset
SQL Analysis Performed

The project includes analysis of:

Total unique customers
Number of orders per customer
Repeat customer identification
Customer retention percentage
Customer review score distribution among customers
Customer lifetime value analysis
