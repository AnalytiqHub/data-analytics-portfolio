# SQL Portfolio Projects

## Overview

This repository contains SQL-based data analysis projects focused on solving real-world business problems using e-commerce data.

The projects demonstrate skills in data cleaning, SQL querying, business analysis, KPI development, and generating actionable insights from relational databases.

Tools and technologies used:

* SQL (PostgreSQL)
* Relational Database Analysis
* Data Aggregation
* Business Intelligence Concepts
* GitHub Portfolio Management
