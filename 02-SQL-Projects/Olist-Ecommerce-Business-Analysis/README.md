
# Olist E-commerce Customer Analysis Using SQL

## Project Overview

This project analyzes customer behavior using SQL on the Brazilian E-commerce Public Dataset by Olist.

The objective is to answer business questions related to customer acquisition, customer retention, and purchasing behavior.

---

## Business Problem

The business wants to understand:

- Who are our customers?
- Which regions have the highest customer base?
- How many customers return and purchase again?
- Which customers generate the most revenue?

---

## Dataset

Source:
Brazilian E-Commerce Public Dataset by Olist

Tables Used:

- olist_customers_dataset
- olist_orders_dataset
- olist_order_items_dataset
- olist_order_payments_dataset
- olist_products_dataset
