Olist Product Analysis
Project Overview

This project analyzes product performance using the Olist Brazilian E-commerce dataset. The objective is to identify high-performing product categories, understand customer purchasing behavior, evaluate customer satisfaction through review scores, and uncover opportunities to improve product performance and profitability.

The analysis was performed using SQL by joining multiple tables, including products, order items, and customer reviews.

Objectives
Identify the product categories generating the highest revenue.
Determine which product categories sell the most items.
Find the top-performing products by revenue.
Compare average selling prices across product categories.
Analyze customer review scores by product category.
Identify categories receiving the most customer reviews.
Detect products with high revenue but low customer ratings.
Evaluate freight costs across different product categories.
Dataset

The project uses the following Olist datasets:

olist_products_dataset
olist_order_items_dataset
olist_order_reviews_dataset
